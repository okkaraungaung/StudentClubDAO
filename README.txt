SETUP
1. Copy `contracts/StudentClubDAO.sol` into Remix.
2. Compile with Solidity 0.8.20 or newer.
3. Deploy using the MetaMask environment.
4. Copy the deployed contract address into `lib/dao.js`.
5. Run `npm install` if needed.
6. Start the app with `npm run dev`.
7. Open `http://localhost:3000`.
8. The deployer is the admin and an executive member.
9. Admin creates a payment period before adding other members.
10. Added members connect MetaMask, create a nickname, and enter the dashboard.
